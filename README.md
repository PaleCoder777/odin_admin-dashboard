# Int. HTML && CSS Project: Admin Dashboard

## Source
- [The Odin Project, Fullstack JavaScript Path, Intermediate HTML && CSS Course, Grid Section, Project: Admin Dashboard](https://www.theodinproject.com/lessons/node-path-intermediate-html-and-css-admin-dashboard)


## Scope
- HTML and CSS, focus on CSS grid structuring
- The base project is to create a web page to resemble the following [project design file](https://raw.githubusercontent.com/TheOdinProject/curriculum/43cc6ab69fdfbef40d431a65677d2144668930ac/intermediate_html_css/grid/project_admin_dashboard/imgs/dashboard-project.png)
- Project scaffolding created with CSS Grid and content positioning with flexbox 
- No implementation of responsiveness or JavaScript expected in this project


## Key Reflection Points
- CSS Styling Organization
    - I use comments to group my selectors, so as I create the HTML, the styling is parallel to elements I'm adding. When going back to style something, I can easily find the selectors

- Filter Property
    - The icons were originally black, so I used the filter properties to change the icons to white. There could be other websites that have a color option prior to downloading the files

- Google Chrome Dev Tools
    - At this point, being able to use the dev tools that allow me to see the lines of flexbox and grid make the visualization so much simpler. With so many nested elements, it is easy to get lost and apply styling to the wrong element, but selecting an element w/ dev tools, I can pinpoint exactly what I need to target.

### Closing Thoughts
- A solid step up in layout complexity from the previous Sign up form project, allowing me to become more comfortable with designing web pages and laying out the structure with a combo of CSS Grid and flexbox.
